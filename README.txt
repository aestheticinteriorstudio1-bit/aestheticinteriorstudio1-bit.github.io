A responsive one-page website for Aesthetic Interior Studio.

## How to use
Open `index.html` in Chrome to preview the website.

## How to publish
The folder can be uploaded to a static hosting service. If you want to use your own domain, connect the domain inside the hosting provider after uploading.

The enquiry form opens WhatsApp with the customer's details; no separate server/database is required.
